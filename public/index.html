Frequently Asked Questions

Common questions about inter-college participation, passes, and Gemma AI.

How do students from visiting colleges and universities register?
Visiting students select "External University Participant" on registration, enter their institution name and college roll ID, and immediately receive a cryptographic QR pass. At the security gate, they present this pass along with their physical college photo ID for instant verification.
How does Gemma 2 AI automate schedule generation?
Gemma AI uses structured zero-shot prompting with strict schema constraints. Given an event title, category, and expected attendance, it plans synchronized hourly slots (Registration, Inauguration, Keynote, Lunch Break, Hackathon Sprint, Valedictory) without speaker overlap.
What happens if an attendee's QR ticket cannot be scanned at the gate?
Gate security volunteers can use the Gate Scanner's manual code override. Simply type in the 6-character attendee ticket code (e.g. TC-9018) or student roll ID into the input field to authenticate the registration and mark the attendee as admitted.
How are vendor purchase orders (Catering, Decor, AV) coordinated?
The Vendors Procurement view tracks assigned contracts, delivery status, and meal headcounts with vegetarian/non-vegetarian tallies. Gemma AI automatically factors a 10% safety buffer into catering counts so student participants never experience shortages.
